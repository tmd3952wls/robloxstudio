# 시네마틱 Roblox 3D 쇼츠 — 통합 설계 (테스트 단계)

기존 프로젝트(`불과물의마을`, `수명을파는시장`, `별이떨어지는마을`)는 건드리지 않고 이 폴더에서만 시험한다.

## 폴더
```
시네마틱_테스트/
  lib/
    assets.py        Poly Haven(CC0) 다운로더 + catalog.json (카테고리·라이선스·해상도·용량)
    pbr.py           Principled BSDF PBR 재질 (Base/Normal/Rough/Disp→Bump/ARM, 반복 감추기, 바닥 오염)
    mesh.py          재질별 상자·쐐기·원기둥 조립 (미터 단위 UV)
    buildings.py     절차적 중세 건물 (돌 1층·반목조·돌출층·박공지붕·굴뚝·창·문·덧문·창턱·화분)
    terrain.py       침식 능선 산맥·강 골짜기·마을 평지·화산(분화구·용암 줄기) + 경사/높이 재질 섞기 + 강물
    town.py          거리·집 배치(겹침 검사)·돌다리·강둑 석축·숲(지오메트리 노드 인스턴스)·소품 인스턴스
    fx.py            불꽃·연기 기둥(볼륨)·화산 분연·분수·불티
    look.py          HDRI·태양·안개(대기 원근)·카메라(DOF)·AgX·EEVEE/Cycles 프리셋
    roblox_char.py   R6 블록 캐릭터(하루 고정 디자인 포함) + 자세 적용 + 걷기
    world_valley.py  '불과 물의 마을' 세계 조립 (테마별 world_*.py 를 추가하는 구조)
    perf.py          렌더 시간·RAM·VRAM 기록 (out/perf_log.jsonl)
  emotion/
    face.py          매개변수형 만화 얼굴 (눈·눈꺼풀·동공·눈썹·입·이·혀·눈물·땀·볼터치·그늘선)
    library.py       감정 라이브러리 12종 (얼굴·몸짓·전환시간·부위별 순서·떨림·시선·깜빡임) + 캐릭터별 스타일
    anim.py          감정 타임라인 (이어지는 전환·깜빡임·시선·떨림·호흡·눈물 흐름·립싱크)
    auto.py          대본 → 감정 자동 연결 (감정 열 / 키워드 규칙 / timing.json)
  tests/             scene_a.py, scene_street.py(B·C), faces_test.py, t_house.py
  assets/            내려받은 CC0 에셋 (git 제외)
  out/               렌더 결과 (git 제외)
```

## 전체 흐름 (주제 하나 → 쇼츠)
1. 주제 → 대본(대사·화면·카메라·**감정** 열) — Claude 가 작성·자체 검토 (기존 규칙 유지)
2. 음성 fish.audio → timing.json (기존 그대로)
3. 장면별 환경 결정 → `world_<테마>.py` 선택/조합 (에셋 라이브러리 + 절차적 생성)
4. 캐릭터 배치 (roblox_char OUTFITS) — Roblox Studio 는 새 캐릭터 의상이 필요할 때만
5. 감정: auto.build_timeline(대본, timing) → 캐릭터별 Timeline
6. 군중·이펙트 (town/fx)
7. 카메라·조명 (shots.py 방식 유지: 컷마다 움직이는 드론 카메라, 빨려 들어가는 접근)
8. 렌더 (EEVEE 기본, 200프레임 청크·건너뛰기·분리 프로세스 — 기존 render_full.py 방식)
9. 조립 (기존 make_subs / make_mix / ffmpeg 그대로)
